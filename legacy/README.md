# Historical SGP4 imitation experiment

These scripts, notebooks and figures belong to the previous SGP4-generated-label
experiment. They are archived for provenance, are not maintained, and do not
support claims about correcting SGP4 against measured orbits. Historical results
must not be compared with the controlled benchmark in the repository root.
The old checkpoint files are stored locally in checkpoints/ and remain ignored.
Use the root command `python -m src.run_benchmark` for the supported experiment.
